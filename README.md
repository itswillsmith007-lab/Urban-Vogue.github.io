# Urban Vogue — GitHub Website Theme

A responsive, static ecommerce-style homepage for GitHub Pages.

## Upload to GitHub
1. Extract this ZIP.
2. Open the extracted `urban-vogue-theme` folder.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to your GitHub repository.
4. In GitHub, open **Settings → Pages** and select your main branch/root folder.
5. Save and open the generated GitHub Pages URL.

No backend or payment gateway is included; this is a front-end theme. Replace the demo product cards and buttons with your own store/order system when ready.
